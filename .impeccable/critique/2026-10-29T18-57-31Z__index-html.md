## Fix first

### 1. P1 — Sharing needs unmistakable meaning

Owner-row **Copy link** copies owner-only URL, not recipient access. Meanwhile **Share** hides until hover/focus. Root sharing identifies target as **`.`**.

That creates two risks: sending unusable links, or misunderstanding how much gets shared.

**Fix:** distinguish “Copy owner-only link” from “Share”; keep Share discoverable. Root dialog should say **“All files and folders”**, with explicit whole-tree scope. Preserve permissions and future-files warning.

Sources: `index.html:483–485`, `index.html:883–902`.
Command: `/impeccable clarify`

### 2. P2 — Toolbar prioritizes expert controls over core task

`Aa`, `""`, `.*` receive permanent space. On 390px viewport, toolbar occupies **132px across three rows**. These controls demand interpretation before users need them.

**Fix:** put advanced matching behind one labeled “Filter options” control. Keep ordinary filtering immediate. Preserve advanced features; reduce their default prominence.

Sources: `index.html:331–341`, `index.html:380–399`.
Command: `/impeccable distill`

### 3. P2 — Compact targets become fiddly on phones

Measured filename links **22.5px high**, row actions **28px high**, rows **36px**. Layout fits narrow screens, but fitting is not comfortable tapping.

**Fix:** enlarge clickable areas on coarse-pointer devices toward **44px**; preserve desktop density. Update virtual row-height calculation alongside CSS.

Source: `index.html:260–310`.

### 4. P2 — No matches looks like missing content

Unmatched filter leaves blank list; only small `0 / 208 items` explains why. Count has no live announcement.

**Fix:** one inline state: **“No matching files” + “Clear filter.”** Distinguish genuinely empty folder. Announce result changes politely—no modal or toast.

### 5. P3 — Row rules compete with filenames

Bright full-width dividers create stronger repeated rhythm than content. Plain interface still feels busier than necessary.

**Fix:** soften row separators only. Preserve readable text, clear control borders, hover feedback and focus indicators. No zebra striping, cards, or new visual system needed.

## Cognitive load and user risks

**Moderate load:** hierarchy and progressive disclosure need work—not number of files.

- **First-timer:** can mistake owner URL for recipient share link.
- **Mobile user:** compact targets increase precision required.
- **Keyboard/screen-reader user:** sampled keyboard path works; silent result counts weaken feedback.

Journey starts confidently, dips at empty results or sharing ambiguity, then recovers through expiry and copy feedback. Fix uncertainty, not personality.
